# МИП «ПрогнозРНМ» — корпоративный сайт

Публичный сайт: **https://butenko7991-stack.github.io/**.

В репозитории находится готовая статическая версия сайта: HTML, CSS, JavaScript и изображения. GitHub Pages публикует ветку `main`, папку `/` (корень репозитория). Файл `.nojekyll` отключает обработку Jekyll. Любое обновление опубликованных файлов в `main` вызывает новую сборку Pages.

## Содержание

Главная страница, сведения о компании, услуги, каталог оборудования с девятью карточками, IT-решения, экология и водоочистка, проекты, партнёры, контакты, политика обработки персональных данных и страница ошибки 404.

## Обновление

Измените нужные HTML-файлы и отправьте изменения в `main`. Базовые стили находятся в `styles.css`, новый визуальный слой — в `innovation.css`, контакты — в `contact-hub.css`. Основная интерактивность — в `main.js`, выбор направлений и панель связи — в `innovation.js`, изображения — в `assets/`. Проверяйте `sitemap.xml` после изменения структуры страниц.

Метаданные canonical и Open Graph настроены на адрес GitHub Pages. При привязке другого домена обновите абсолютные адреса в HTML, `sitemap.xml` и `robots.txt`.

## Фирменный стиль и контакты

Основной фирменный цвет — жёлтый (`#FFD43A`), дополненный графитовым фоном и спокойным бирюзовым акцентом цифровых технологий. На первом экране можно переключить инженерное направление, цифровые двойники и водоочистку.

Очистка воды выделена как приоритетное направление компании и выбрана на первом экране по умолчанию. Пункт навигации «Очистка воды» сохраняет адрес `/ekologiya`. На главной есть отдельный блок `#voda`; на странице направления — отраслевые решения, схема процесса из презентации, примеры испытаний, отдельные сценарии исходного фильтрата и концентрата после осмоса, полный цикл проекта и запрос расчёта. Показатели из материалов не являются гарантией для любого состава стока. Стили блоков находятся в `priority.css`.

Телефон и почта видны в шапке. На всех страницах есть панель «Связаться». На главной и контактной странице доступен адрес офиса со ссылкой на карту, копирование почты и скачивание `contacts.vcf` в адресную книгу. Адрес производственной площадки на сайте не публикуется.

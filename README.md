# МИП «ПрогнозРНМ» — корпоративный сайт

Публичный сайт: **https://butenko7991-stack.github.io/**.

В репозитории находится готовая статическая версия сайта: HTML, CSS, JavaScript и изображения. GitHub Pages публикует ветку `main`, папку `/` (корень репозитория). Файл `.nojekyll` отключает обработку Jekyll. Любое обновление опубликованных файлов в `main` вызывает новую сборку Pages.

## Содержание

Главная страница, сведения о компании, услуги, каталог оборудования с девятью карточками, IT-решения, экология и водоочистка, проекты, партнёры, контакты, политика обработки персональных данных и страница ошибки 404.

## Обновление

Измените нужные HTML-файлы и отправьте изменения в `main`. Общие стили находятся в `styles.css`, интерактивные элементы — в `main.js`, изображения — в `assets/`. Проверяйте `sitemap.xml` после изменения структуры страниц.

Метаданные canonical и Open Graph настроены на адрес GitHub Pages. При привязке другого домена обновите абсолютные адреса в HTML, `sitemap.xml` и `robots.txt`.

## Формы

Формы создают письмо в почтовом клиенте посетителя на `prognozrnm@mail.ru`. Серверная отправка и CRM не подключены.

## Изображения

Фотографии оборудования и иллюстрации технологий взяты из материалов заказчика. Изображения `gen-hero.jpg`, `gen-workshop.jpg`, `gen-control.jpg` — сгенерированные атмосферные иллюстрации, не документальные фотографии компании. Их можно заменить собственной съёмкой.

Политика обработки данных и актуальность технических показателей требуют согласования владельцем сайта перед использованием в деловой коммуникации.
